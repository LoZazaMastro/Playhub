## Built For The Living Room

- Big Picture first: install the Playhub CSS Loader theme and keep your Steam artwork backed up.
- Xbox Game Bar automation: Playhub keeps the controller Game Bar shortcut off in Big Picture, then enables it only while Xbox or Microsoft Store games need it.
- Streaming-ready: Gaming Mode can prepare Sunshine, Apollo or Vibepollo before Steam starts.
- Repair tools: one button checks Gaming Mode, its Decky companion plugin, UWPHook, the agent and configuration.
- Diagnostics: Playhub can create a report on the desktop when something needs investigating.
- Updates: Playhub checks GitHub for new app and plugin versions and notifies you in-app.

## Download And Install

1. Open the [latest release](https://github.com/LoZazaMastro/Playhub/releases/latest).
2. Download `Playhub-Setup.exe`.
3. Run the installer, choose your language and click `Install`.

Playhub installs for your Windows user. Windows 11 x64 is recommended. Windows
10 can run the app with a solid dark theme instead of acrylic effects.
